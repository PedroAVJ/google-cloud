- `assets/google-cloud-icon.svg`

SVG geometry. Created in this repository for the public release; no provider
logo, official application artwork, font, or external icon library was copied.

`assets/gmail-small.svg`, `assets/gmail.png`, `assets/gmail-logo.png`, and the
assets under `skills/gmail/assets/` and `skills/gmail-inbox-triage/assets/` are
copied from the OpenAI Gmail plugin at commit
`11c74d6ba24d3a6d48f54a194cd00ef3beea18f9` (`assets/gmail-logo.png` is its
`assets/logo.png`). `skills/gmail-cli/assets/gmail-app-icon.png` is a
byte-identical copy of the upstream `assets/gmail.png`. See
`THIRD_PARTY_NOTICES.md`. No Google endorsement is implied.

## YouTube

`assets/youtube-icon.svg` and `skills/youtube/assets/youtube-icon.svg` are an
